# 📈 Stock Portfolio Tracker

A simple, lightweight, and versatile **Stock Portfolio Tracker** built in pure Python. It allows users to build, monitor, and calculate real-time valuations of their stock investments through both an **interactive Terminal CLI** and a **sleek Dark-Themed Tkinter GUI**.

Developed as an internship project for **CodeAlpha**.

---

## 🚀 Features

### 💻 Command-Line Interface (`stock_portfolio_tracker.py`)
- **Zero External Dependencies**: Runs entirely on Python's standard library.
- **Interactive Menu**: Intuitive, loop-driven CLI to add stocks, inspect holdings, and compute totals.
- **Robust Input Validation**: Validates stock ticker symbols and enforces positive integer quantities.
- **Automatic Aggregation**: Automatically merges and increases share counts when adding existing holdings.
- **File Export**: Generates and exports formatted portfolio summaries to `portfolio_summary.txt`.

### 🖥️ Modern Graphical User Interface (`stock_portfolio_tracker_gui.py`)
- **Modern Dark Theme**: Styled with a tailored palette (`#0D1117`, `#161B22`, `#58A6FF`, `#3FB950`, `#E3B341`).
- **Live Valuation Calculation**: Automatically calculates the total value as you type in share quantities.
- **Interactive Holdings Table**: Built with `ttk.Treeview`, featuring alternating row colors and dynamic scrolling.
- **Holdings Management**: Add shares, view live summary metrics, and remove selected positions with a single click.
- **Custom Export**: Save summaries via native operating system file dialogs.
- **Built-in Stock Reference**: Displays a scrollable sidebar with all supported stocks, company names, and benchmark prices.

## ⚙️ Prerequisites & Setup

### Requirements
- **Python 3.8+** installed on your system.
- Tkinter (included by default with standard Python installations on Windows and macOS).

> [!NOTE]
> No `pip install` commands are required! Both versions use only Python built-in modules (`tkinter`, `ttk`, `messagebox`, `filedialog`).

### Verification
Check your Python installation:
```bash
python --version
```

## 🎮 How to Run

### 1. Running the GUI Version (Recommended)
Launch the dark-themed desktop application:
```bash
python stock_portfolio_tracker_gui.py
```

#### GUI Controls:
1. Select a stock symbol from the dropdown menu.
2. Enter the number of shares (notice the live value preview update automatically).
3. Click **"+ Add to Portfolio"**.
4. To remove a position, click any row in the portfolio table and hit **"Remove Selected Row"**.
5. Click **"Save Portfolio"** in the top navigation bar to export your summary to a text file.

---

### 2. Running the CLI Version
Launch the terminal application:
```bash
python stock_portfolio_tracker.py
```

#### CLI Menu Options:
- **`[1] Add a stock to portfolio`**: Enter symbol (e.g. `AAPL`) and quantity of shares.
- **`[2] View current portfolio`**: Shows a formatted breakdown of holdings, prices, and total valuation.
- **`[3] Save & Exit`**: Prompts whether to export results to `portfolio_summary.txt` and cleanly exits.

## 🛠️ Customization

To add your own stocks or update benchmark prices, update the dictionary at the top of either file:

### In `stock_portfolio_tracker.py`:
```python
STOCK_PRICES = {
    "AAPL": 189.30,
    "TSLA": 177.82,
    # Add your own stocks here:
    "GOOG": 175.98,
}
```

### In `stock_portfolio_tracker_gui.py`:
```python
STOCKS = {
    "AAPL": ("Apple Inc.", 189.30),
    "TSLA": ("Tesla Inc.", 177.82),
    # Add your own stocks here:
    "GOOG": ("Alphabet Inc.", 175.98),
}
```
